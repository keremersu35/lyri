lyrics that land on every word

Give it a song, get word-level timestamped lyrics (JSON, LRC, SRT, ASS) and a Brat-style lyric video — all computed on your own Mac.

▶ Try the demo ★ Source on GitHub

How it works

🎤SplitDemucs pulls the vocals out of the mix and finds where someone is actually singing.
📝Find the wordsYour pasted lyrics, or LRCLIB — verified against what Whisper hears. Nothing found? Whisper writes them down.
🎯AlignA CTC model trained on songs places every character; each word is shown at its first vowel, when you hear it.
🎬RenderEach distinct frame is drawn once and x264 repeats it — a 3-minute 1080×1920 video in under 20 seconds.

Run it

Needs an Apple Silicon Mac, ffmpeg and uv. The heavy lifting runs locally; nothing is uploaded anywhere.

brew install ffmpeg uv
git clone https://github.com/keremersu35/lyri && cd lyri
uv run lyri app          # web app at http://127.0.0.1:8700
